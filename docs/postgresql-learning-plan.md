# PostgreSQL 学习计划

> 创建时间: 2026-03-22
> 目标: 掌握 PostgreSQL 数据库基本知识和实际运用

---

## 📋 学习阶段划分

### 阶段 1: 基础入门 (Day 1-2)
**目标**: 了解 PostgreSQL 是什么，能安装并运行基本操作

| 序号 | 主题 | 内容 |
|------|------|------|
| 1.1 | PostgreSQL 简介 | 历史、特点、与 MySQL 对比 |
| 1.2 | 安装部署 | Docker 安装、本地安装、连接工具 |
| 1.3 | 基础概念 | 数据库、表、行、列、数据类型 |
| 1.4 | 基本 SQL | CREATE, INSERT, SELECT, UPDATE, DELETE |
| 1.5 | 练习 | 创建一个测试数据库，插入查询数据 |

---

### 阶段 2: 核心操作 (Day 3-5)
**目标**: 掌握日常开发中常用的数据库操作

| 序号 | 主题 | 内容 |
|------|------|------|
| 2.1 | 数据类型详解 | 数值、字符串、日期时间、JSON、数组 |
| 2.2 | 表设计 | 主键、外键、约束、默认值、自增 |
| 2.3 | 查询进阶 | WHERE, ORDER BY, LIMIT, JOIN, 子查询 |
| 2.4 | 索引 | 索引类型、创建索引、索引优化 |
| 2.5 | 事务 | ACID、BEGIN/COMMIT/ROLLBACK |
| 2.6 | 练习 | 设计一个实际业务表结构 |

---

### 阶段 3: 进阶特性 (Day 6-8)
**目标**: 了解 PostgreSQL 高级特性，提升开发效率

| 序号 | 主题 | 内容 |
|------|------|------|
| 3.1 | 视图 (View) | 创建视图、物化视图 |
| 3.2 | 函数与存储过程 | PL/pgSQL、自定义函数 |
| 3.3 | 触发器 | 自动触发逻辑 |
| 3.4 | JSON/JSONB | NoSQL 能力、JSON 查询 |
| 3.5 | 全文搜索 | 文本搜索、模糊匹配 |
| 3.6 | 练习 | 实现一个带触发器的业务场景 |

---

### 阶段 4: 运维与优化 (Day 9-10)
**目标**: 了解数据库维护和性能优化

| 序号 | 主题 | 内容 |
|------|------|------|
| 4.1 | 备份与恢复 | pg_dump、pg_restore、逻辑备份 |
| 4.2 | 用户与权限 | 角色、权限管理、安全 |
| 4.3 | 性能优化 | 慢查询分析、EXPLAIN、VACUUM |
| 4.4 | 监控 | 常用监控指标、日志分析 |
| 4.5 | 练习 | 配置一个生产环境数据库 |

---

### 阶段 5: 实战项目 (Day 11-14)
**目标**: 综合应用，完成一个完整项目

| 序号 | 项目 | 内容 |
|------|------|------|
| 5.1 | 设计阶段 | 需求分析、ER 图设计 |
| 5.2 | 开发阶段 | 建表、写 SQL、存储过程 |
| 5.3 | 优化阶段 | 索引优化、查询优化 |
| 5.4 | 部署阶段 | Docker 部署、备份策略 |

---
