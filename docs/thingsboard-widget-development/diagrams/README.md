## 渲染方式

### 方式1: VS Code + Mermaid 插件
1. 安装插件: Markdown Preview Mermaid Support
2. 打开 .mmd 文件
3. 预览即可看到图表

### 方式2: Typora
1. 打开 .mmd 文件
2. 自动渲染 Mermaid 图表

### 方式3: 在线编辑器
- https://mermaid.live/
- 复制代码粘贴即可预览

### 方式4: Markdown 文件
```markdown
```mermaid
[复制 .mmd 文件内容]
```
```
