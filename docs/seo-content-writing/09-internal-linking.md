# 第九章：内部链接策略

## 9.1 什么是内部链接？

> **内部链接** 是指同一网站内页面之间的链接。

### 内部链接的作用

```
对搜索引擎:
├── 帮助爬虫发现和索引页面
├── 传递页面权重 (PageRank)
├── 理解网站结构和内容关系
└── 确定页面重要性

对用户:
├── 提供相关内容导航
├── 延长停留时间
├── 降低跳出率
└── 改善用户体验
```

---

## 9.2 内部链接类型

### 导航链接

```
位置:
├── 主导航菜单
├── 页脚链接
├── 侧边栏导航
└── 面包屑导航

特点:
├── 模板级链接
├── 每个页面都有
├── 传递权重较少
└── 主要用于导航
```

### 上下文链接

```
位置:
├── 正文内容中
├── 相关文章推荐
└── "阅读更多"链接

特点:
├── 内容级链接
├── 相关性高
├── 传递权重多
└── 提升用户体验

最佳实践:
├── 自然融入内容
├── 使用描述性锚文本
├── 链接到相关内容
└── 控制每页链接数量
```

### 相关文章链接

```
位置:
├── 文章底部
├── 侧边栏
└── 内容中间

类型:
├── "相关文章"
├── "你可能喜欢"
├── "继续阅读"
└── "热门文章"
```

## 9.3 内部链接策略

### 支柱页面策略 (Pillar Strategy)

```
结构:
                    ┌─────────────┐
                    │   支柱页面   │
                    │  (Pillar)   │
                    │  综合指南    │
                    └──────┬──────┘
                           │
           ┌───────────────┼───────────────┐
           │               │               │
    ┌──────┴──────┐ ┌──────┴──────┐ ┌──────┴──────┐
    │  集群页面   │ │  集群页面   │ │  集群页面   │
    │  (Cluster) │ │  (Cluster) │ │  (Cluster) │
    │  子主题    │ │  子主题    │ │  子主题    │
    └─────────────┘ └─────────────┘ └─────────────┘

链接关系:
├── 支柱页面 → 集群页面 (导出链接)
├── 集群页面 → 支柱页面 (导入链接)
└── 集群页面之间互相链接

示例:
支柱: "SEO 完全指南"
├── 集群: "关键词研究"
├── 集群: "内容优化"
├── 集群: "技术 SEO"
└── 集群: "链接建设"
```

### 权重分配策略

```
高权重页面:
├── 首页
├── 支柱页面
├── 高流量页面
└── 重要产品页

权重流向:
├── 从高权重页面链接到新页面
├── 帮助新页面快速索引
└── 提升新页面排名

注意事项:
├── 不要只从页脚链接
├── 从正文内容链接更有价值
├── 避免过多链接稀释权重
```

## 9.4 锚文本优化

### 锚文本类型

```
精确匹配:
├── "SEO 写作指南"
└── 包含完整关键词

部分匹配:
├── "学习 SEO 写作"
└── 包含关键词变体

品牌锚文本:
├── "Backlinko"
└── 使用品牌名

通用锚文本:
├── "点击这里"
├── "了解更多"
└── 避免过度使用

裸链接:
├── "https://example.com"
└── 直接使用 URL
```

### 锚文本最佳实践

```
✓ 使用描述性锚文本
✓ 自然融入内容
✓ 关键词变体多样化
✓ 保持锚文本简洁
✓ 链接到相关内容

✗ 过度使用精确匹配
✗ 使用 "点击这里"
✗ 链接到不相关页面
✗ 锚文本过长
```

---

## 9.5 内部链接检查清单

```
链接数量:
□ 每页至少 3-5 个内部链接
□ 不超过 100 个链接
□ 正文链接优先

链接质量:
□ 链接到相关内容
□ 使用描述性锚文本
□ 避免断链
□ 定期更新链接

链接分布:
□ 支柱页面有足够导入链接
□ 新页面有来自高权重页面的链接
□ 深层页面有入口链接
□ 避免孤立页面
```
