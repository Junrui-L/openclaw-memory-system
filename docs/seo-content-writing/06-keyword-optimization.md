## 6.2 关键词密度与自然使用

### 关键词密度公式

```
关键词密度 = (关键词出现次数 / 总词数) × 100%

建议密度:
├── 主关键词: 1-2%
├── 次要关键词: 0.5-1%
└── LSI 关键词: 自然分布

示例:
文章长度: 2000 字
主关键词 "SEO 写作" 出现次数: 20 次
密度: 20/2000 × 100% = 1% ✓
```

### 自然使用原则

```
✓ 读起来自然流畅
✓ 符合上下文语境
✓ 同义词替换使用
✓ 长尾变体分布

✗ 强行插入关键词
✗ 堆砌关键词
✗ 影响阅读体验
```

## 6.4 页面元素关键词优化

### 完整优化清单

```
1. URL 优化
├── 包含主关键词
├── 使用短横线分隔
├── 全小写字母
└── 示例: /seo-content-writing-guide

2. H1 标题优化
├── 包含主关键词
├── 放在标题前部
├── 长度 50-60 字符
└── 示例: "SEO 写作完全指南：10 个技巧提升排名"

3. H2/H3 标题优化
├── 包含关键词变体
├── 自然融入标题
└── 示例: "SEO 写作技巧 #1: 关键词研究"

4. 首段优化
├── 前 100 字包含关键词
├── 自然引入主题
└── 示例: "SEO 写作是提升搜索排名的关键..."

5. 图片 ALT 优化
├── 描述图片内容
├── 包含关键词
└── 示例: "SEO 写作流程图"

6. 内部链接优化
├── 锚文本包含关键词
├── 链接到相关页面
└── 示例: "学习更多 SEO 技巧"

7. 元描述优化
├── 包含主关键词
├── 吸引点击
├── 长度 150-160 字符
└── 示例: "学习 SEO 写作技巧，提升文章排名..."
```
