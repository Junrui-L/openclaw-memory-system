## 5.3 标题优化 (H1)

### H1 标题公式

```
公式1: 数字 + 关键词 + 利益点
├── "10 个 SEO 写作技巧，让你的文章排名飙升"
├── "5 步学会关键词研究，新手也能上手"
└── "7 种内容类型，满足所有搜索意图"

公式2: 关键词 + 修饰词 + 承诺
├── "SEO 写作完全指南：从入门到精通"
├── "关键词研究方法：2024 年最新版"
└── "搜索意图分析：提升排名的秘密武器"

公式3: 问题 + 解决方案
├── "为什么你的文章不排名？SEO 结构优化指南"
├── "如何写出高排名文章？10 个实用技巧"
└── "SEO 新手必看：文章结构优化全攻略"
```

### H1 最佳实践

```
✓ 包含主关键词
✓ 长度 50-60 字符
✓ 吸引眼球，激发好奇
✓ 承诺具体价值
✓ 使用数字、括号、冒号
✗ 关键词堆砌
✗ 过于笼统
✗ 超过 70 字符
```

## 5.4 引言写作 (Introduction)

### 引言结构: PAS 公式

```
P - Problem (问题)
├── 描述读者面临的问题
├── 使用 "你是否..." 开头
└── 让读者产生共鸣

A - Agitation (激化)
├── 强调问题的严重性
├── 描述不解决的后果
└── 增加紧迫感

S - Solution (解决方案)
├── 介绍文章将提供的解决方案
├── 承诺具体价值
└── 引导继续阅读

示例:
"你是否写了几十篇文章，但搜索排名却始终上不去？
(Problem)

每天辛苦创作，却看不到流量增长，这种挫败感让人想要放弃。
更可怕的是，你的竞争对手正在抢走你的潜在客户...
(Agitation)

别担心，这篇文章将分享 10 个经过验证的 SEO 写作技巧，
帮助你快速提升文章排名，获取更多自然流量。
(Solution)"
```

## 5.5 正文结构优化

### H2/H3 标题层级

```
层级结构示例:

H1: SEO 写作完全指南
│
├── H2: 什么是 SEO 写作
│   ├── H3: SEO 写作的定义
│   ├── H3: SEO 写作 vs 普通写作
│   └── H3: 为什么 SEO 写作重要
│
├── H2: SEO 写作核心技巧
│   ├── H3: 关键词优化
│   │   ├── 关键词研究
│   │   └── 关键词布局
│   ├── H3: 内容结构优化
│   └── H3: 用户体验优化
│
├── H2: SEO 写作工具推荐
│   ├── H3: 关键词研究工具
│   ├── H3: 内容优化工具
│   └── H3: 排名监测工具
│
└── H2: 常见问题解答

规则:
├── H1: 只能有 1 个
├── H2: 主要章节 (3-7 个)
├── H3: 子章节 (每个 H2 下 2-5 个)
└── H4+: 少用，保持简洁
```

---

### 段落结构

```
标准段落结构:

主题句 (Topic Sentence)
├── 概括段落主旨
├── 通常放在段首
└── 包含关键词

支持句 (Supporting Sentences)
├── 解释主题句
├── 提供证据/示例
└── 详细说明

过渡句 (Transition)
├── 连接下一段
├── 保持文章流畅
└── 可选

示例段落:
"关键词研究是 SEO 写作的基础。
(主题句)

通过深入研究用户搜索的关键词，
你可以了解他们的真实需求，
从而创作出更符合搜索意图的内容。
(支持句)

接下来，让我们看看如何进行有效的关键词研究。
(过渡句)"
```

## 5.6 内容可读性优化

### 可读性检查清单

```
文本格式:
□ 段落长度: 2-4 句
□ 句子长度: 15-25 字
□ 使用主动语态
□ 避免长难句
□ 使用过渡词

视觉元素:
□ 每 300 字配 1 张图
□ 使用列表 (有序/无序)
□ 使用表格对比
□ 加粗关键信息
□ 使用引用框

结构元素:
□ 清晰的 H2/H3 标题
□ 目录导航 (长文)
□ 总结框
□ CTA 按钮
□ 内部链接
```
