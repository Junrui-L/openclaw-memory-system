# 第二章：关键词研究与选择

## 2.1 什么是关键词？

> **关键词** 是用户在搜索引擎中输入的词语或短语，用于找到他们需要的信息。

### 关键词类型

```
┌─────────────────────────────────────────────────────────────┐
│                    关键词类型金字塔                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │              头部关键词 (Head)                      │   │
│  │  • 1-2 个词                                        │   │
│  │  • 搜索量高 (10万+)                                │   │
│  │  • 竞争激烈                                        │   │
│  │  • 例: "SEO"                                       │   │
│  └─────────────────────────────────────────────────────┘   │
│                           │                                 │
│              ┌────────────┴────────────┐                   │
│              │                         │                   │
│  ┌───────────┴───────────┐   ┌────────┴────────┐          │
│  │    主体关键词 (Body)   │   │  长尾关键词      │          │
│  │  • 2-3 个词           │   │  (Long-tail)    │          │
│  │  • 搜索量中等         │   │  • 4+ 个词      │          │
│  │  • 竞争中等           │   │  • 搜索量低     │          │
│  │  • 例: "SEO 技巧"     │   │  • 竞争低       │          │
│  │                       │   │  • 转化率高     │          │
│  │                       │   │  • 例: "如何    │          │
│  │                       │   │    学习 SEO     │          │
│  │                       │   │    写作"        │          │
│  └───────────────────────┘   └─────────────────┘          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 2.2 关键词研究的重要性

### 为什么需要关键词研究？

1. **了解用户需求** - 知道用户在搜索什么
2. **找到流量机会** - 发现高价值关键词
3. **评估竞争难度** - 选择可排名的关键词
4. **内容策略指导** - 规划内容主题

### 关键词研究数据指标

| 指标 | 说明 | 工具来源 |
|------|------|---------|
| **搜索量** | 月均搜索次数 | Google Keyword Planner, SEMrush |
| **关键词难度** | 排名竞争程度 (0-100) | Ahrefs, SEMrush |
| **CPC** | 每次点击费用 | Google Ads |
| **搜索意图** | 用户搜索目的 | SERP 分析 |
| **趋势** | 搜索量变化趋势 | Google Trends |

## 2.3 关键词研究方法

### 方法1: Google 自动补全

```
在 Google 搜索框输入关键词，观察自动补全建议：

输入: "SEO"
建议: 
- SEO 是什么意思
- SEO 优化
- SEO 教程
- SEO 工具
- SEO 公司

输入: "如何学习 SEO"
建议:
- 如何学习 SEO 优化
- 如何学习 SEO 写作
- 如何学习 SEO 技术
- 如何学习 SEO 入门
```

**优点**: 免费、真实搜索数据
**缺点**: 无量化数据

### 方法3: 竞争对手分析

```
步骤:
1. 找出行业 Top 竞争对手
2. 分析他们的排名关键词
3. 找到内容空白机会

工具: Ahrefs, SEMrush, Ubersuggest
```

**分析维度**:
- 竞争对手排名关键词
- 他们的内容类型
- 内容长度和深度
- 反向链接数量

### 关键词选择标准

#### 1. 搜索意图匹配

```
搜索类型          关键词示例              内容类型
─────────────────────────────────────────────────────────
信息型 (Informational)   
├── "什么是 SEO"        → 指南、教程
├── "如何学习 SEO"      → 步骤教程
└── "SEO 技巧"          → 列表文章

导航型 (Navigational)
├── "SEMrush 官网"      → 品牌页面
├── "Ahrefs 登录"       → 登录页面
└── "Backlinko 博客"    → 首页

交易型 (Transactional)
├── "SEO 工具推荐"      → 产品对比
├── "SEMrush 价格"      → 定价页面
└── "购买 SEO 课程"     → 销售页面

商业型 (Commercial)
├── "最佳 SEO 工具"     → 评测文章
├── "SEMrush vs Ahrefs" → 对比文章
└── "SEO 工具评测"      → 评测合集
```

#### 2. 竞争度评估

```
关键词难度 (KD) 评估:

KD 0-30: 容易 ⭐⭐⭐⭐⭐
├── 新网站可排名
├── 内容质量优先
└── 例: "如何学习 SEO 写作"

KD 31-60: 中等 ⭐⭐⭐
├── 需要一定权威
├── 内容 + 外链
└── 例: "SEO 写作技巧"

KD 61-100: 困难 ⭐
├── 大品牌主导
├── 需要长期投入
└── 例: "SEO"
```

#### 3. 商业价值评估

```
高商业价值关键词特征:
✓ 包含购买意向词: "购买", "价格", "优惠", "推荐"
✓ 具体问题: "最佳...", "如何...", "哪个..."
✓ 地域限定: "北京 SEO 公司", "上海..."
✓ 行业细分: "B2B SEO", "电商 SEO"
```

   - 平均每月搜索量
